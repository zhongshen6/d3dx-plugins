GameBanana 仓库插件 (gb_warehouse)

用于在 Mods 仓库中浏览 GameBanana 模组，并提供三栏工作流：
左侧列表、中间详情、右侧下载。

[v1.4.1] 当前特性：
- 列表浏览：分页、预取、封面缓存、搜索、首页返回
- 列表信息：标题两行省略、作者/浏览/时间、NSFW 标志
- 详情区：简介文本、图片组切换、全屏预览、浏览器打开详情页
- 下载区：多文件下载、按钮内进度条、下载后自动唤起导入
- 分类浏览：根分类下子分类列表、手动分类 ID 跳转
- 翻译表：仅使用中/英/日词表，按语言分别下载后合并（单语言失败不阻断）
- 数据源设置：支持按当前环境保存 Game ID 与根分类 ID
- 更新检查：状态栏触发检查、mods_manage 按钮状态与高亮联动


使用说明：
1. 打开 “Mods 仓库” 页面，插件会自动加载列表。
2. 点击封面可打开详情；在详情区可切图、全屏预览或浏览器查看。
3. 点击下载按钮可下载并自动打开导入流程。
4. 点击“分类”可浏览子分类，点击“更新翻译表”可刷新分类词表。
5. 左下角状态栏可查看当前任务进度与结果。
